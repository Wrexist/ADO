# LEARNINGS.md

One line per learning. The nightly analyzer (parked, p5) consumes this file; keep entries terse and factual.

- 2026-07-12: Per-model prompt tuning is cheaply done as a preamble + optional per-model variant over one shared `body` — avoids duplicating every prompt per AI while still shaping output for the selected model.
- 2026-07-12: Specialized "agents" are best modeled as dispatch profiles (system preamble + verifiable loop + exit check), not new runtime types — they compose with existing prompts via a render helper and need no runner changes.
- 2026-07-12: Custom user data (prompts) follows the same secure pattern as secrets — gitignored JSON under data/, token-gated CRUD, built-ins served from the client bundle so the API payload stays small.
- 2026-07-12: The catch-up scheduler must NOT advance a job's last-run on failure, or a failing nightly job silently marks itself done and never retries; only a clean run persists the timestamp.
- 2026-07-12: Sub-minute samplers (sysmon 10s, health 60s) should stay on naked intervals — a missed 10s sample is meaningless, so persisting last-run for them is pure overhead; the scheduler is for catch-up-worthy daily/hourly work.
- 2026-07-12: WAL-safe backup = `VACUUM INTO` (not a file copy) + reopen-and-assert row count before rotation; a silent short-write must fail loudly rather than leave a corrupt "backup".
- 2026-07-12: Vitest path filters are resolved from the repo root (where the config lives), not the `-w` workspace cwd — filter with `apps/server/src/...` from root, not `src/...`.
- 2026-07-12: The dashboard already holds at 53 repos with no layout break because both views cap their lists (View A grid at 6, View B table at 5, each + "View all") — capping list widgets defensively pays off at scale for free.
- 2026-07-12: Pixel-diff visual baselines should wait until after the pixel-polish sign-off (p3.5) or they just get re-baselined by the polish; a render + zero-console-error smoke gate gives regression coverage in the meantime without that churn.
- 2026-07-12: launchd starts with a minimal PATH, so a LaunchAgent must invoke the app via a login shell (`/bin/sh -lc`) to pick up node/nvm — running `node` directly from a plist fails after reboot.
- 2026-07-12: The server has no JS build (runs via tsx), so autostart (pm2/launchd) invokes `npm run start -w @ado/server` rather than a compiled entrypoint.
- 2026-07-12: A stable event id is correct ONLY for create-once/idempotent facts; for anything whose value changes over time (scanner rescans, GitHub PR/CI enrichment) a stable id makes the bus dedup silently drop every update — use a fresh id per emit and let the reducer merge.
- 2026-07-12: EventSource can't set headers, so the SSE token rides the URL; the default request logger serializes req.url and writes the secret to disk — redact `token=` in a req serializer (header tokens are safe).
- 2026-07-12: A concurrency-slot decrement must live in `finally`, not after the last await — otherwise one throw both leaks the slot forever and becomes an unhandledRejection (the run was launched with `void`).
- 2026-07-12: Trend deltas stay honest by storing daily snapshots as events and computing current − baseline; no history → no delta. Boot captures before the async scan finishes, so re-capture post-scan (unique id + last-write-per-day-wins in the reducer) to correct day one.
- 2026-07-12: A "lint" gate step that's an echo is worse than none — it reads green while checking nothing. Wire ESLint (flat config + typescript-eslint) scoped to the gaps tsc misses (unused vars, explicit-any); a clean codebase surfaces ~0 findings, so the cost is low and the honesty is high.
- 2026-07-12: Kill dead nav without faking features — route data-backed items to real bus-rendered pages and route not-yet-built items to one honest `/planned/:slug` placeholder; a `SectionHeader.actionTo` (Link) turns every "View all" into real navigation.
- 2026-07-12: A ⌘K command palette that indexes the live bus + pages is the honest replacement for a decorative search box, and it doubles as fast navigation across the whole app.
- 2026-07-12: Drop a superseded drizzle table with a NEW migration (DROP TABLE + journal entry) — never edit an applied migration's SQL; that breaks the hash check and existing DBs refuse to migrate.
- 2026-07-12: Latest-only signals (health/tokens/stats) persisted append-only grow the log forever even though the reducer keeps only the newest; a boot-time compaction that deletes all but max(seq) per key is state-preserving and keeps replay fast.
- 2026-07-12: `node --check` is the WRONG validator for Claude Code Workflow scripts — it rejects the top-level `return`/`await` those scripts rely on, because the harness runs the body inside an async function. Validate by compiling the source as an AsyncFunction body (with the injected globals as params) — it parses without executing and accepts exactly what the harness accepts.
- 2026-07-12: In a Workflow script a phase is assigned two ways — a `phase('X')` call OR `phase: 'X'` in an agent's opts (the opts form is the one to use inside pipeline/parallel stages, so concurrent stages don't race the global phase() state) — so a "declared vs used phases" check must count both forms or it false-flags the canonical pattern.
- 2026-07-12: CI should mirror the local gate exactly (`npm run verify`) — but a step that needs secrets or a browser (the Playwright `smoke`) stays a local/manual gate rather than being faked green in CI; an honest "skipped, and why" beats a hollow pass, same rule as the UI's no-fabrication.
- 2026-07-12: A bodyless `fetch` POST that still sends `content-type: application/json` makes Fastify 400 ("Body cannot be empty…"); send `{}` (or drop the header). React StrictMode double-invokes mount effects in dev, so the smoke's zero-console-error gate saw it twice — that gate earns its keep by catching client/server contract slips a green typecheck can't.
- 2026-07-12: For a "catalog" view of on-disk artifacts (the workflow recipes), have the server read + parse the REAL files (extract just the balanced `meta` literal, eval that in isolation) rather than hand-maintaining a parallel copy — the visual then can't drift, and an unparseable file is skipped, not guessed (no-fabrication for reference data too).
- 2026-07-12: A one-click "install" button from a web UI is safe ONLY when the local server derives the command from a first-party allow-list keyed by an id the client sends (never a command string), token-gated, minimal-env, timed-out. And be honest about the ceiling: a dashboard can auto-install CLI tools/extensions but never a GUI app or an account login — those must be guided (open installer / copy command / sign in), not fake buttons.
- 2026-07-12: The agent runner authenticates via the `claude` CLI's OWN login (Pro/Max session under ~/.claude), NOT the dashboard's ANTHROPIC_API_KEY (which is stripped from the child env) — so "connect your subscription" means installing + signing in the CLI on the host, and the Setup page must say so plainly instead of implying the API-key box powers agents.
